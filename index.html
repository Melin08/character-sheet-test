In-Depth Guide: How to retrieve character JSON from PC on Parchment
  1. Open your web browser and navigate to pconparchment.com.
  2. Log in and open the specific character sheet you want to export into Adventurer Codex.
  3. Open your browser's Developer Tools by pressing F12 (or right-click anywhere on the webpage and select Inspect).
  4. In the DevTools top toolbar, switch to the Network tab and click Fetch/XHR.
  5. Refresh your browser page (F5 or Ctrl+R / Cmd+R).
  6. Click on the request named characters or beginning with rest/v1/characters, select the Response tab, and copy all of it.

Stuck or need help? Contact me on Discord (lmp2620).

In-Depth Guide: How to retrieve character JSON from D&D Beyond
Direct API URL
  1. Set your D&D Beyond character privacy to Public and copy your numeric Character ID from the URL.
  2. Open: https://character-service.dndbeyond.com/character/v5/character/YOUR_ID_HERE
  3. Copy all the raw JSON text and paste it below.
