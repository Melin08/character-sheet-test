Universal Character Importer

In-Depth Guide: How to retrieve character JSON from PC on Parchment
  1. Open your web browser and navigate to pconparchment.com.
  2. Log in and open the specific character sheet you want to export into Adventurer Codex.
  3. Open your browser's Developer Tools by pressing F12 (or right-click anywhere on the webpage and select Inspect).
  4. In the DevTools top toolbar, switch to the Network tab.
  5. Directly below the Network tab, click the Fetch/XHR filter button so you only see API data requests.
  6. Refresh your browser page (F5 or Ctrl+R / Cmd+R) while keeping DevTools open.
  7. In the list of network requests that appear on the left, click on the request named characters or one beginning with rest/v1/characters.
  8. On the right side of DevTools, select the Response tab (next to Headers/Payload).
  9. Click inside the JSON response text, select all of it (Ctrl+A or Cmd+A), and copy it (Ctrl+C or Cmd+C).
  10. Return here and paste that copied text into the box below (or save it as a .json file and click "Upload Saved JSON File").

Stuck or need help? contact me on Discord (lmp2620).

In-Depth Guide: How to retrieve character JSON from D&D Beyond
Option A (Fastest: Direct API URL)
  1. Open your character on D&D Beyond and look at the web browser address bar (e.g. https://www.dndbeyond.com/characters/12345678). The number at the end is your Character ID.
  2. In your character sheet preferences on D&D Beyond, ensure your character privacy is set to Public.
  3. In a new browser tab, go directly to:
    https://character-service.dndbeyond.com/character/v2/character/YOUR_ID_HERE
  4. Select all the raw text (Ctrl+A or Cmd+A) and copy it (Ctrl+C or Cmd+C).
Option B (Via DevTools Network Inspection)
  1. On your D&D Beyond character sheet, press F12 (or right click > Inspect) to open Developer Tools.
  2. Select the Network tab, then click the Fetch/XHR filter below it.
  3. Refresh the sheet (F5 or Ctrl+R).
  4. In the network requests list on the left, click on the request showing your numeric Character ID (or matching character).
  5. Click the Response tab on the right, select all the text (Ctrl+A), and copy it.
